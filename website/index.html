Installation

1

Download

Download the appropriate .xpl file for your platform from the downloads section above.

2

Create Directory

Create the plugin directory: X-Plane/Resources/plugins/OpenALSharedExample/

3

Copy Files

Copy the .xpl file to this directory and add a sound.wav file (any WAV file will work).

4

Restart X-Plane

Restart X-Plane and load any aircraft - the plugin will automatically play a sound.
